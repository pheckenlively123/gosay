<objective>
Wire the full flag surface into the CLI (RENDER-08 eyes/tongue + HELP-01 help), and register the wrap/think flags whose engine support landed in Plans 02-03. This is the final integration slice that makes every Phase 3 capability user-invocable:

- `-e <eyes>` / `-T <tongue>` pass verbatim into `RenderOpts.Eyes`/`Tongue` (D-05, any length, no validation).
- `-W <cols>` (int, default 0 → engine uses 40) and `-n` (bool) drive `RenderOpts.Width`/`NoWrap` (RENDER-05 CLI surface).
- `--think` (long-only, no `-t` alias per D-12) drives `RenderOpts.Think`.
- `-h`/`--help` print the full documented usage to stdout and exit 0 (D-13/D-14); error usage stays on stderr + non-zero (D-13).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| argv (-W/-e/-T/--think/-h) → run() flag parsing | Untrusted flag values; -e/-T pass verbatim into the render |
| argv -W value → wrap engine | Integer width controls per-line column budget |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Tampering | -e/-T verbatim pass-through (e.g. terminal escape sequences) | accept | Verbatim pass-through is the intended, documented behavior (D-05); ANSI/color is explicitly out of scope. The user owns the consequences of escape glyphs they pass. No sanitization required (RESEARCH Security Domain). |
| T-03-09 | Denial of Service | -W 0 / negative / absurdly large | mitigate | `flag.IntVar` rejects non-numeric values (parse error → stderr + exit 1). Width<=0 is treated as default-40/no-wrap in Render (Plan 02, Pitfall 6); a huge -W just produces a wide single line bounded by input length — no allocation proportional to the width value. |
| T-03-10 | Information Disclosure | error/help text leaking internal paths | accept | Help text is a static constant; parse-error path prints a fixed one-line usage. Unknown-cow errors already avoid path disclosure (Phase 2). No internal path is emitted. |
</threat_model>
