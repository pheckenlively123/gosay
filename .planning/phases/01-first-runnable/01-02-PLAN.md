<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream repo → vendored copy | The 50 `.cow` files cross from `cowsay-org/cowsay` (network) into the gosay repo at vendoring time |
| embedded FS → parser | Cow file bytes cross from `embed.FS` into Plan 01-03's parser; they are static at compile time but originate from untrusted upstream content (text editors can inject control characters in art) |
| `cowFS.ReadDir` → user | Phase 2 `-l` will surface cow names to stdout — those names come from filenames in `internal/cowsay/cows/` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | Tampering | upstream cow file integrity | mitigate | `SOURCE.md` pins the exact commit SHA `027c9268ac8571408e153214b9cf1a5e6fab0cfc`. The vendoring procedure references the tag, but the SHA in `SOURCE.md` is the authoritative integrity anchor; any re-vendor that produces a different SHA must be reviewed. Acceptance criterion `grep -q "027c9268ac8571408e153214b9cf1a5e6fab0cfc"` enforces presence. |
| T-01-02-02 | Tampering | line-ending corruption on Windows checkouts | mitigate | `.gitattributes` (set in Plan 01-01) declares `cows/*.cow text eol=lf`; this plan ensures vendored files are LF at commit time (`! file internal/cowsay/cows/*.cow | grep -q CRLF`). Together they make CRLF corruption unreachable. |
| T-01-02-03 | Information disclosure | accidental embedding of secrets via `//go:embed all:cows` | mitigate | Use the explicit `//go:embed cows/*.cow` glob (per PITFALLS.md Pitfall 7); the embed pattern matches only `.cow` files, so `NOTICE` and `SOURCE.md` are NOT embedded into the binary, and any `.DS_Store` / `.git*` file in the directory is silently excluded. Acceptance criterion greps the file for the exact directive. |
| T-01-02-04 | Tampering | malicious .cow content (output injection via control characters or terminal escapes) | accept | Cow files are vendored from `cowsay-org/cowsay` v3.8.4 — a 25-year-old well-maintained upstream. ANSI escape sequences in cow art could in principle reach the user's terminal at render time, but no current upstream file contains them (verified by RESEARCH §A spot-check). Future refreshes are gated by `SOURCE.md` review. Mitigating output injection (e.g., stripping `\x1b`) would harm legitimate art and is out of scope for Phase 1. |
| T-01-02-05 | Repudiation / licensing | missing or wrong NOTICE for vendored files | mitigate | This plan's Task 1 explicitly creates `NOTICE` with upstream attribution, per-file license variances (apt/gnu/suse/kangaroo), and the dedicated `daemon.cow` provenance paragraph naming Marshall Kirk McKusick. PITFALLS.md Pitfall 3 names this as the gating issue for public release. Acceptance criteria grep for `Marshall Kirk McKusick`, `Fedora`, `apt.cow`, and `WTFPL`. |
| T-01-02-SC | Tampering | npm/pip/cargo installs | n/a | No third-party packages installed in this plan. `embed.go` uses stdlib (`embed`, `sort`, `strings`) only. Package legitimacy gate not applicable to this plan. |
