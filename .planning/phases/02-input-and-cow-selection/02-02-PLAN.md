<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args / stdin → renderer → terminal | message content (positional args or piped stdin) and the `-f` value are untrusted input that flows into Render and out to the terminal |
| `-f <name>` → embed.FS lookup | the cow name is concatenated into an embed.FS path inside LoadCow |
| os.Stdin → io.ReadAll | piped input is read fully into memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | unknown-cow error path | mitigate | `errors.Is(err, cowsay.ErrUnknownCow)` branch prints only `gosay: unknown cowfile %q` (the user-supplied name), never the wrapped `cows/<name>.cow` path. Acceptance criteria assert stderr does NOT contain `cows/`. Severity: LOW, mitigated. |
| T-02-02 | Tampering / EoP | `-f` value in embed.FS path | accept | embed.FS is read-only, compile-time, in-memory; traversal names (`../etc/passwd`) fail `fs.ValidPath` and resolve to fs.ErrNotExist → routed to the clean ErrUnknownCow message. No disk read exists. Severity: LOW. |
| T-02-03 | Information Disclosure | terminal escape sequences in message content | accept | Message bytes are placed inside the ASCII balloon and written verbatim, matching upstream cowsay. gosay does not interpret escapes; any terminal-escape rendering is the receiving terminal's behavior, identical to `echo`/`cat`. Severity: LOW for a local toy CLI reading the user's own input; documented as accepted, no sanitization (would break legitimate content and diverge from cowsay). No HIGH-severity threat. |
| T-02-04 | Denial of Service | unbounded io.ReadAll(os.Stdin) | accept | A local user piping their own input can already exhaust memory with `cat hugefile`. gosay is a single-shot local CLI with no privilege boundary and no remote input; bounding the read would break legitimate large-message piping and diverges from cowsay. Severity: LOW (self-inflicted, local, no trust boundary crossed). Accepted; revisit only if gosay ever runs as a service (out of scope per PROJECT.md). |
</threat_model>
