       - State A (marker == ""): for each line, try heredocOpen.FindStringSubmatch. On match, set marker to the capture group and switch to state B. Otherwise skip the line silently.        - State B (marker != ""): for each line, compute stripped := strings.TrimRight(line, "\r") (CRLF safety per RESEARCH section C-Q8). If stripped equals marker, join the collected lines with `\n`, apply cowBodyUnescape.Replace, and return the result with nil error. Otherwise append scanner.Text() (the unstripped line) to the collected slice.
       - At EOF: if marker == "" return errors.New with text "no heredoc opener found in cow file"; if marker != "" return fmt.Errorf with text including the captured terminator name (e.g., `heredoc terminator "EOC" not found`).

    2. Unexported func buildBalloon(message string) string. Algorithm per RESEARCH section D:
       - Split message on `\n` via strings.Split into lines. Empty input ("") becomes the slice [""] - do not optimize this case; Phase 2's INPUT-04 will refine it. The simplest non-panicking behavior here is the goal.
       - Compute maxWidth as the max displayWidth across lines (start at 0; iterate; track max).
       - Build the result with a strings.Builder b.
       - Write top border: b.WriteString(" " + strings.Repeat("_", maxWidth+2) + " \n"). The +2 accounts for the single space on each side of the text inside the balloon (per RESEARCH Phase-1 Pitfall 3).
       - Write body:
         - If len(lines) == 1: write fmt.Sprintf("< %-*s >\n", maxWidth, lines[0]).
         - If len(lines) >= 2: iterate i from 0 to len(lines)-1; pick left/right border chars by index: i==0 gives left `/` right `\`; i==len(lines)-1 gives left `\` right `/`; otherwise both are `|`. Then write fmt.Sprintf("%s %-*s %s\n", left, maxWidth, lines[i], right).
       - Write bottom border: b.WriteString(" " + strings.Repeat("-", maxWidth+2) + " \n").
       - Return b.String().

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| embedded FS → parser | Cow file bytes cross from embed.FS (compile-time-fixed) into parseCowBody; static data but originated from upstream content |
| message argument → balloon | User-supplied message string crosses into buildBalloon; may contain any printable / control characters; flows to stdout in Plan 01-04 |
| RenderOpts → substitution | Eyes/Tongue/Thoughts values are substituted verbatim into cow body; in Phase 1 only the renderer itself sets them (no external input path), but the substitution sink will receive user input via -e/-T in Phase 3 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03-01 | Tampering | malformed cow file causing parser infinite loop or panic | mitigate | parseCowBody uses bufio.Scanner with bounded buffer (64KB initial, 1MB max via scanner.Buffer); scanner naturally terminates at EOF; if no terminator is found, parseCowBody returns a typed error rather than looping. TestParseCowBody_NoTerminator and TestParseCowBody_NoOpener enforce these error paths. |
| T-01-03-02 | Denial of service | unbounded message length flooding the balloon builder | accept | buildBalloon allocates O(maxWidth × len(lines)) bytes; Phase 1 has no word wrap so a 1 MB single-line message produces a 1 MB balloon.
